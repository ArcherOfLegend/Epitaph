# Epitaph
Rollback netcode for JoJo's Bizarre Adventure: All-Star Battle R.

You need [JoJoAPI](https://github.com/Kapilarny/JAPI) 4.0.1 installed first. Then drop `RollbackLab-launcher.exe` and the `japi` folder from the release zip into your ASBR game directory and run the launcher.

The use of other mods, whether they are JAPI mods or file mods, could cause conflicts. For the smoothest experience, please make sure you do not have any mods installed before playing this mod.

## If something breaks
